# Address-Book
📌 Description
This project is a Telephone Directory Management System developed in C.
It allows users to store and manage contact details such as name, mobile number, and email ID.
The system supports operations like adding, searching, editing, deleting, and displaying contacts.
It uses structures for data organization and file handling to save and retrieve data

## ⚙️ Features
- Add Contact
- Search Contact (by name, mobile, email)
- Edit Contact
- Delete Contact
- Display Contacts
- Save & Load contacts using file handling

## 🛠️ Concepts Used
- Structures
- Arrays
- Functions
- File Handling
- Input Validation
  
## ▶️ How to Run
1) gcc *.c -o addressbook
2) ./addressbook
